# 输入法语言自动切换器

一个基于WPF的Windows应用程序，可以根据当前活动的应用程序自动切换输入法语言。

## 功能特点

- 🔄 **自动切换**：监控活动窗口变化，自动切换到预设的输入法语言
- ⚡ **快捷设置**：检测到未配置的应用时，自动显示快捷设置面板，一键设置输入法
- ⚙️ **灵活配置**：为不同的应用程序设置不同的输入法语言
- 🚀 **开机自启**：支持设置开机自动启动
- 📊 **实时监控**：显示当前应用程序和输入法状态
- 🔔 **系统托盘**：最小化到系统托盘，不占用任务栏空间
- 💾 **配置保存**：所有配置自动保存，重启后自动加载

## 系统要求

- Windows 10/11
- .NET 8.0 Runtime（如果使用自包含发布版本则无需安装）

## 使用说明

### 1. 启动程序

运行 `auto-tool.exe` 启动程序。

### 2. 添加应用配置

#### 方法一：快捷设置（推荐）⭐

1. 点击"启动监控"按钮
2. 切换到你想要配置的应用程序
3. 返回本程序窗口，会自动显示"快捷设置当前应用的输入法"面板
4. 选择输入法语言，点击"设置为当前应用的默认输入法"按钮
5. 完成！

#### 方法二：手动添加

1. 在上方输入框中填写：
   - **应用名称**：自定义的应用名称（如：Visual Studio Code）
   - **进程名称**：应用的进程名（如：Code，不需要.exe后缀）
   - **输入法语言**：选择该应用使用的输入法语言
2. 点击"添加"按钮保存配置

### 3. 启动监控

点击"启动监控"按钮，程序将开始监控活动窗口的变化，并自动切换输入法。

### 4. 管理配置

- **编辑**：点击配置列表中的"编辑"按钮修改配置
- **删除**：点击"删除"按钮删除不需要的配置
- **启用/禁用**：勾选或取消勾选"启用"列来控制配置是否生效

### 5. 系统托盘

- 关闭窗口时，程序会最小化到系统托盘
- 双击托盘图标可重新显示主窗口
- 右键托盘图标选择"退出"可完全退出程序

## 如何获取进程名称

1. 打开任务管理器（Ctrl+Shift+Esc）
2. 切换到"详细信息"选项卡
3. 找到目标应用程序，查看"名称"列（不含.exe后缀）

## 开发构建

```bash
# 还原依赖
dotnet restore

# 编译项目
dotnet build

# 运行程序
dotnet run

# 发布为自包含单文件可执行程序（推荐）
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish

# 或使用发布脚本
publish.bat
```

## 分发说明

### 📦 如何打包分发

1. 运行 `publish.bat` 生成发布文件
2. 将整个 `publish` 文件夹打包（包含 `auto-lang.exe` 和 `assets` 文件夹）
3. 分发给用户

### ⚠️ 重要提示

- **必须包含 assets 文件夹**：程序运行时需要加载图标资源
- **自包含模式**：用户无需安装 .NET Runtime
- **文件大小**：约 80-150MB（包含运行时）

### 📝 给用户的说明

用户收到文件后：
1. 解压整个文件夹到任意位置
2. 双击 `auto-lang.exe` 即可运行
3. 无需安装任何依赖

## 常见问题

### Q: 为什么切换不生效？
A: 请确保：
1. 已正确安装目标语言的输入法
2. 进程名称填写正确（不包含.exe）
3. 配置已启用
4. 已点击"启动监控"

### Q: 如何找到应用的进程名？
A: 打开任务管理器，在"详细信息"选项卡中查看应用的进程名称。

### Q: 可以设置快捷键吗？
A: 当前版本不支持快捷键功能，但会在后续版本中考虑添加。
